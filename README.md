# MediIoT

MediIoT adalah aplikasi simulator Rekam Medis Elektronik (RME)
yang terintegrasi dengan perangkat IoT melalui Elitech MedLink.
Program ini dibuat dengan tujuan menjadi project dummy yang membuktikan pelayanan MedLink sebagai middleware dalam Integrasi IoT.
MediIoT diasumsikan menjadi program pihak ketiga atau program yang digunakan oleh fasilitas kesehatan.
Tujuan lain dari program ini adalah sebagai program internal perusahaan yang menggunakan fasilitas MedLink untuk melakukan pemeriksaan pada pekerja di perushaan.
